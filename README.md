# Jobby App

A job search web application built with React.js, where users log in and browse job listings and job details.

## Features
- Login page with authentication
- Protected routes: pages open only after login, otherwise redirects to login
- Jobs page listing available jobs fetched from a REST API
- Job details page for each job
- Header navigation and a Not Found page for invalid URLs

## Tech Stack
React.js, React Router, Styled Components, REST API (fetch)

## Run locally
1. Clone the repo
2. `npm install`
3. `npm start`
